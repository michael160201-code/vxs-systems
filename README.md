# VXS Main Site (vxs.systems)

This is the main brand landing page for VXS Industrial Intelligence.

- **Live at**: https://vxs.systems
- **Product subdomain**: https://fde.vxs.systems
- **Visual system**: VXS VI V2.3 (Sterile Industrial Intelligence)
- **Tech**: Static HTML + CSS, GitHub Pages

## Deployment

1. Push to `main` branch
2. GitHub Pages deploys from `main` branch, root folder
3. Custom domain: `vxs.systems` (CNAME file)
4. DNS: CNAME record pointing to `michael160201-code.github.io`

## Defensive Domains

- `vxsindustrial.com` → redirects to `vxs.systems`
- `vxsintelligence.com` → redirects to `vxs.systems`
